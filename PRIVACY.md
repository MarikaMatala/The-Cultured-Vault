# Privacy and data handling / Tietosuoja ja tietojen käsittely

**Repository / Projekti:** The Cultured Vault  
**Last reviewed / Tarkistettu:** 11 November 2026

## Suomeksi

### Soveltamisala
Nykyinen sovellusranko on vain luku -tilassa ja käyttää repositorion julkista aloituskatalogia. Siinä ei ole käyttäjätilejä, kirjautumista, tietokantayhteyttä, tunnistautumista, käyttäjien arvioiden tai kirjastojen tallennusta eikä projektin omaa analytiikkaa. Haku ja suodatus tehdään selaimessa julkista aineistoa vasten. Nykyinen versio ei aseta projektin omia evästeitä eikä lähetä kävijän syötteitä ylläpitäjälle. Jos tuleviin versioihin lisätään tilejä, tallennusta, Supabase-yhteys, ulkoisia metatietopalveluita tai analytiikkaa, tietosuojatiedot ja oikeusperusteet on päivitettävä ennen ominaisuuksien käyttöönottoa. GitHub ja mahdollinen hosting-palvelu käsittelevät teknisiä lokitietoja omien käytäntöjensä mukaan.

### Rekisterinpitäjä ja yhteydenotot
Tämän projektin lähdekoodin ja dokumentaation ylläpitäjä on Marika Matalamäki. Tietosuojaa koskevat kysymykset voi lähettää osoitteeseen marika.matalamaki@gmail.com. Tämä yhteystieto ei tarkoita, että projekti keräisi kävijöiden henkilötietoja.

### Evästeet ja analytiikka
Projektin ylläpitäjä ei lisää tähän projektiin omia mainos- tai seurant evästeitä eikä omaa analytiikkapalvelua, ellei tässä dokumentissa tai sovelluksen dokumentaatiossa nimenomaisesti toisin kerrota. GitHubin, GitHub Pagesin, hosting-palvelun ja ulkoisten palveluiden tekninen tietojenkäsittely määräytyy niiden omien tietosuojakäytäntöjen mukaan. Jos projektin toiminnallisuus tai palveluntarjoajat muuttuvat, tämä dokumentti päivitetään.

### Oikeudet ja lisätiedot
Voit pyytää itseäsi koskevien mahdollisten projektin ylläpitäjän hallussa olevien tietojen tarkastamista tai poistamista ottamalla yhteyttä yllä mainittuun sähköpostiosoitteeseen. Lakisääteiset oikeudet riippuvat siitä, käsitelläänkö henkilötietoja ja millä oikeusperusteella. GitHubin omiin tietoihin liittyvät pyynnöt tulee osoittaa GitHubille.

## English

### Scope
The current application scaffold is read-only and uses the repository's public starter catalogue. It has no user accounts, sign-in, database connection, authentication, saved member ratings or libraries, or project-owned analytics. Search and filtering run in the browser against public data. The current version does not set project-owned cookies or send visitor input to the maintainer. If future versions add accounts, persistence, a Supabase connection, external metadata providers or analytics, this privacy notice and the applicable legal bases must be reviewed before those features are enabled. GitHub and any hosting provider process technical logs under their own policies.

### Controller and contact
The source code and documentation for this project are maintained by Marika Matalamäki. Privacy questions can be sent to marika.matalamaki@gmail.com. This contact detail does not mean that the project collects visitor personal data.

### Cookies and analytics
The project maintainer does not add project-owned advertising or tracking cookies or a project-owned analytics service unless expressly stated in this document or the application documentation. Technical processing by GitHub, GitHub Pages, a hosting provider and external services is governed by their own privacy notices. This document should be updated if the project's functionality or providers change.

### Rights and further information
You may contact the maintainer at the email address above to ask about access to or deletion of any personal data about you that the maintainer may hold in connection with the project. The availability of statutory rights depends on whether personal data is processed and on the applicable legal basis. Requests concerning data held by GitHub should be directed to GitHub.
